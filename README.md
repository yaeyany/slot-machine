# Slot Machine

A terminal-based slot machine written in Rust as part of my rust learning journey.

## Features

- Weighted random symbol generation
- Command system
- Score and high score tracking
- Modular architecture
- Error handling (only 1 for now as nothing else should fail in theory)

## Technologies

- Rust
- rand
- thiserror

## Running

```bash
cargo run
```
