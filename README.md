# Slot Machine

A terminal-based slot machine written in Rust as part of my Rust learning journey.

## Features

- Weighted random symbol generation
- Score and high score tracking
- Modular architecture
- Result-based error handling
- Command system with input validation

## Running

Clone the repository:

```bash
git clone https://github.com/yaeyany/slot-machine.git
cd slot-machine
cargo run
```
